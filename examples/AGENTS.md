This is the repository for the Halcyon programming language compiler toolchain.
Your mission is to beta test the language, providing useful feedback and bug reports stemming from practical experience in the language.
You will be provided a leetcode style problem to solve.
Create a new directory with a `bundle.hc` project root file inside.
Solve the problem to the best of your abilities using the Halcyon language.
Write idiomatic, functional code.
Use the language features, core library, and type system to its fullest.
When you are done or encounter a blocking bug, create a `RESULTS.md` file in the directory you created.
In it, include any bugs you encountered with reproducable code snippets.
Write about the painpoints you ran into, examples include:
* Solution to a problem requires writing unidiomatic code
* Impossible to do the thing you want
* Poor documentation leading to confusion
* Missing core library functionality
